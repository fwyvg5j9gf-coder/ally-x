# ally-x — sistema para tu ROG Xbox Ally X con Claude integrado

Hecho para el **ROG Xbox Ally X** (2025, RC73XA, Z2 Extreme, 24 GB). Casi todo
aplica también al ROG Ally X 2024.

Una versión por sistema operativo, cada una hecha a la medida:

| | |
|---|---|
| **[windows/](windows/README.md)** | Windows 11: rendimiento, limpieza, ajustes de portátil, Claude + Claude Code con comandos propios, diagnóstico y revertir con un clic |
| **[bazzite/](bazzite/README.md)** | Bazzite (Linux tipo SteamOS): post-instalación, Claude Code y lanzadores para Modo Juego *(versión inicial, se va a ampliar)* |

## ¿cuál elegir?

| | Bazzite | Windows 11 |
|---|---|---|
| Rendimiento en juegos | igual o mejor en la mayoría (Proton) | nativo, pero cargado de procesos |
| Batería y suspensión | mejor y más confiable | peor; ally-x lo mejora bastante |
| Juegos con anti-cheat (Valorant, Fortnite, CoD) | **no funcionan** | funcionan |
| Game Pass / launchers | parcial | completo |
| Claude | Claude Code + claude.ai como app | app de escritorio + Claude Code |
